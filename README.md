# Star_Wars_API_Task README

-----

## What is this repository?
This repository is setout as 3 tasks using Python, MongoDB and PyMongo.

The three tasks setout are to:
1. Import from https://swapi.dev/ the starships' collection from the API and add it to the MongoDB database.
2. Get characters id from database for pilots
3. Add characters id from task 2 and add to pilots column on starships. Replacing URL.

## What can be found:

- db_config.py: This tests the connection to my database.
- main.py: Currently contains all tasks in function state.
- bugTracker.md: Tracks all bugs I find and how I fixed them.
